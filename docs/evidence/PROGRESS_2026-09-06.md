## Confirmed implementation / 已确认实现

The current code path supports the exact Fabric targets `1.21.11`, `26.1.2`,
and `26.2`; collects Fabric Loader's loaded ModList, selected resource-pack,
and optional shader-pack observations after visible connection-scoped consent;
uploads signed client observations through Velocity/Bungee; and correlates
them with Paper/Folia and provider-compatible server evidence. Client-origin
facts remain `CLIENT_REPORTED / LOW`; controlled fixtures can exercise
`SERVER_CONFIRMED` and `QUARANTINE` under lab policy.

This is not Tencent ACE-equivalent kernel anti-cheat. There is no verified
kernel driver, persistent agent, cross-process memory scanner, debugger or
injection blocker, DMA detector, public precision/recall, or production
kick/deny/ban efficacy. The release authority ceiling remains MONITOR-only.
